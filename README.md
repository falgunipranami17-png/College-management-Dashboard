College Management Dashboard

About: 
A simple College Management System built using Python, Flask, SQLAlchemy, SQLite, HTML, and CSS.
This project provides a single-page dashboard for managing students, branches, clubs, profiles, and student-club assignments.

Features:
Add new branches
Delete branches
Add new clubs
Delete clubs
Add students
Assign a branch to a student
Assign multiple clubs to a student
Remove a student's branch
Remove a student's club
Delete students
Add student profile/bio
Display students, branches, and clubs dynamically
SQLite database using SQLAlchemy ORM
Responsive web interface

Technologies Used:
Python
Flask
SQLAlchemy
SQLite
HTML5
CSS3
Jinja2
